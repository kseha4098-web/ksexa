# ksexa
# Веб-портал подачи заявок жителей в управляющую компанию ЖКХ

## Концепция системы
Веб-приложение для жителей многоквартирных домов и сотрудников управляющей компании. Позволяет жильцам подавать заявки на ремонт и обслуживание (сантехника, электрика, уборка), отслеживать их статус в личном кабинете, а диспетчерам — распределять задачи между исполнителями.

## Технологический стек
* **Фронтенд:** React, HTML5, CSS3, JavaScript
* **Бэкенд:** Node.js / Express
* **СУБД:** MySQL

## Структура папок проекта
/client
клиентская часть (React, страницы личного кабинета и формы заявки)
/server
серверная часть, обработка API запросов
/database
схемы базы данных и SQL-скрипты миграций
.env.example
пример конфигурационного файла окружения
.gitignore
файл исключений для Git
